## module orientation

-  introductory but practical - focus on end user POV
-  lots of Q&A throughout
-  3 reading materials
-  **2 3-people design exercies** (membership can be different)
-  5-8 in-class mini activities
-  1 semester-long design project - involving 2 group submissions
-  journal submissions each week (friday is deadline each week - one sentence is enough)
-  no written exam - 100% CA

## grading breakdown

**individual & group of 3**
design exercise 1 (week 3) - 15%
design exercise 2 (week 7) - 20%
weekly journal entry - 5%
in-class activities (weekly) - 10%
reflection (week 12) - 15%

**group project**
big project framing/spec (week 5) - 15%
big project UI design rationale & evaluation (week 11) - 20%


## terminology

-  user interface = interface or UI
-  user interface design = UI design
-  user experience = UX
-  human-computer interaction = CHI or HCI or interaction design
